# 📚 CGPA Booster

An AI-powered web tool to help CSE students improve their CGPA and SGPA.

## What It Does

- Upload your college syllabus PDF
- Get subject difficulty ratings (Easy / Moderate / Hard / Very Hard)
- Based on worldwide student experience via Claude AI
- Personalized study tips per subject
- CGPA goal calculator
- Backlog clearing planner

## Tech Stack

- React.js
- Claude AI (Anthropic)
- pdfjs-dist
- Firebase (Authentication + Database)
- Deployed on Vercel

## How To Run Locally

1. Clone this repo
2. Run `npm install`
3. Create `.env` file with your Claude API key
4. Run `npm start`
